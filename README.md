# Аеростат Конструктор v0.4

Нативний Android-застосунок (Kotlin, Jetpack Compose, Material 3) для **цивільного** інженерного, освітнього,
метеорологічного та науково-дослідного використання. Рахує геометрію, розкрій і масу плівки оболонки.
Працює повністю офлайн, увесь інтерфейс — українською.

> Застосунок не містить і не повинен містити функцій керування польотом, наведення, маршрутизації,
> скидання вантажу чи автоматизованого баластування.

## Можливості

| Екран | Що робить |
|---|---|
| Головна | Новий проєкт, три нещодавні проєкти, порожній стан |
| Майстер створення | Тип оболонки (конверт зібраний знизу, сфера, циліндр, рукав, груша) → варіант (закрита / відкрита з рукавом) → назва |
| Конструктор оболонки | Розміри та матеріал: великі числові поля, десяткова кома, миттєва валідація, одиниці, (i)-довідки, скидання значень, автозбереження |
| Результати (газ) | Підйомна маса біля землі й на висоті, об'єм газу для наповнення, кількість балонів, баласт, корисний вантаж |
| Результати | Геометрія, площа заготовки, маса плівки, кріплень і разом; розкрій рулону; таблиця викрійки клина; припущення; копіювання значень; PDF-паспорт |
| Довідник | Визначення, формули, припущення, приклади (розрахунок, геометрія, матеріали, газ і атмосфера, безпека) |
| Підбір оболонки | Зворотний розрахунок: за вантажем, висотою і (за потреби) тривалістю підбирає розміри оболонки обраної конструкції та створює з них проєкт |
| Мої проєкти | Відкрити, дублювати, видалити (з підтвердженням) |
| Налаштування | Темна / світла / системна тема, призначення, обмеження |

Адаптивний інтерфейс: на вузьких екранах — нижня навігація; від 600 dp (розкладений смартфон, планшет) —
бічна навігаційна панель і двоколонкові конструктор та результати.

## Моделі та статус валідації

| Тип | Статус | Модель |
|---|---|---|
| Конверт, зібраний знизу | Наближена модель | Площа плівки 2WH (точно), робоча висота H − h; об'єм — верхня оцінка W²(H − h)/π |
| Сферична | Перевірена геометрична модель | S = πD², V = πD³/6; клини w(x) = (πD/N)·sin(2x/D), N_мін = ⌈πD/(B − 2s)⌉ |
| Циліндрична | Перевірена геометрична модель | S = πDL + 2·πD²/4, V = πD²L/4 (ідеальний циліндр, плоскі днища) |
| Поліетиленовий рукав | Наближена модель | Площа стінок 2WL (точно); об'єм — лише верхня оцінка W²L/π |
| Грушоподібна | Розрахунок поки недоступний | Геометрію не перевірено — площа і маса не обчислюються |

Маса плівки: `m = A × (t·10⁻⁶) × ρ`, де A — площа заготовки, м² (= площа деталей × шари × (1 + припуски/100)),
t — товщина, мкм, ρ — густина, кг/м³. Відкритий варіант додає площу рукава-апендикса π·d·l.

Значення з історичного посібника 1978 р. та Google-таблиці **не використовуються** як формули:
їх не перевірено (таблиця надана лише як знімок значень без формул). Натомість газові розрахунки побудовано
на відкритій фізиці: ρ = p·M/(R·T), закон Архімеда, модель МСА. На тестовому прикладі (конверт 6 × 10 м,
збір 1,1 м, водень, 10 км, балони 50 л × 150 атм) ця модель дає ≈ 73 м³ робочого об'єму, ≈ 28 кг підйомної маси,
≈ 24,6 м³ газу біля землі та ≈ 3,3 балона — тобто збігається з практичними значеннями з таблиці.

## Зворотний підбір

Відомі корисний вантаж, висота й тривалість — застосунок шукає розмір:

- **конверт і рукав**: ширина задана рулоном, шукається висота (залежність лінійна);
- **сфера і циліндр**: шукається діаметр (половинним діленням, бо об'єм росте як куб, а площа — як квадрат);
- **груша**: «Розрахунок поки недоступний».

Для рукава фіксованої ширини підйом росте як квадрат ширини, а маса плівки — лінійно за висотою,
тому існує **мінімальна ширина**, нижче якої жодна висота не дасть вантажу; застосунок показує цю межу.

Тривалість впливає на результат лише разом із полем «Втрата підйому за добу»: запас =
підйомна маса × втрата/100 × години/24. Готового значення втрати застосунок не підставляє —
воно залежить від плівки, швів і газу, тому його задає користувач зі своїх вимірів.

Перевірка на вашому випадку: конверт шириною 6 м, збір 1,1 м, водень, 10 км, плівка 30 мкм, баласт 12 %,
коефіцієнт наповнення 72 % і вантаж 20 кг дають висоту **9,73 м** — практично ваші 6 × 10 м.

## Збірка

Потрібні JDK 17 та Android SDK (platform 35, build-tools 35). Gradle завантажить wrapper сам.

```bash
./gradlew clean assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest            # unit-тести (JVM)
./gradlew connectedDebugAndroidTest    # UI-тести на пристрої/емуляторі
```

Або відкрийте папку в Android Studio (Ladybug або новіша) → Gradle Sync → Build › Build APK(s).

CI: `.github/workflows/android.yml` на кожен push у `main` збирає APK, запускає unit-тести, перевіряє підпис
(`apksigner verify`), встановлює APK на емулятор Android 14, запускає UI-тести, знімає скріншоти
вузького та розгорнутого екрана й публікує все в гілку `build-output`.

## Структура

```
app/src/main/java/ua/aerostat/
  core/      — чисті розрахунки без Android (парсер чисел, валідація, геометрія, маса, довідник, паспорт)
  data/      — локальне сховище (DataStore + kotlinx.serialization)
  pdf/       — PDF-паспорт (android.graphics.pdf.PdfDocument)
  ui/        — тема, навігація, екрани, компоненти, усі рядки інтерфейсу (Uk.kt)
app/src/test/        — unit-тести
app/src/androidTest/ — UI-тести та знімки екранів
```

## Відомі обмеження v0.4

- Підйомна маса, об'єм газу, кількість балонів, баласт і корисний вантаж рахуються за відкритими формулами
  (Архімед, рівняння стану ідеального газу, стандартна атмосфера МСА) зі статусом «Наближена модель».
  Не розраховуються: міцність і надлишковий тиск оболонки, аеродинаміка, намерзання, вітрове навантаження;
  немає алгоритмів скидання баласту, стравлювання газу чи керування польотом.
- Точність підйомної маси визначається точністю об'єму: для конверта й рукава об'єм — верхня оцінка,
  тому задайте коефіцієнт наповнення зі свого практичного досвіду.
- Грушоподібна оболонка: геометрію не перевірено — «Розрахунок поки недоступний».
- Конверт, зібраний знизу: площа і маса плівки точні; об'єм — лише верхня оцінка, бо перевіреної геометричної моделі зібраного низу немає.
- Рукав: об'єм — лише верхня оцінка (циліндр того ж периметра); сплющені кінці не моделюються.
- Сфера: клини з синусоїдальним профілем; при малій кількості клинів реальна форма гранчаста.
- Густини LDPE/LLDPE/HDPE — орієнтовні; для точного результату вводьте значення з паспорта плівки.
- Зворотний підбір шукає один розмір за фіксованої решти: для рукава й конверта ширина задається користувачем,
  для циліндра — пропорція. Оптимізації за кількома параметрами одночасно немає.
- Тривалість польоту враховується лише через коефіцієнт втрати підйому, який задає користувач; власної моделі
  просочування газу крізь плівку застосунок не має.
- Збірка лише debug (підпис налагоджувальним ключем). Для публікації потрібен власний release-ключ.
- Мова інтерфейсу примусово українська; бібліотечні системні підказки Android можуть залежати від мови системи.
- Перевірено на емуляторі Android 14 (вузький екран 1080×2400 і розгорнутий 2208×1840). Реальні складані пристрої не тестувалися.
